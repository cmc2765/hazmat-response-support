Example request

Retrieve the first five evaluated levels for 60Co.

GEThttp://www.nndc.bnl.gov/ensdf-api/levels?nuclide=60Co&limit=5
curl "http://www.nndc.bnl.gov/ensdf-api/levels?nuclide=60Co&limit=5"

Common endpoints

Use list endpoints to discover records and apply scientific filters.

  • /nuclidesNuclide discovery
  • /datasetsEvaluated datasets
  • /levelsNuclear levels
  • /gammasGamma transitions
  • /decaysDecay records

API features

The API is designed for both direct inspection and reproducible data analysis.

Scientific filters

Filter evaluated quantities using documented units, ranges, identifiers, and presence checks.

Controlled responses

Use pagination, sparse field selection, and optional comments to limit response size.

Data provenance

Connect records to their datasets, references, source files, and evaluation context.

Machine-readable contract

Use the published OpenAPI document to inspect or generate clients for the service.
